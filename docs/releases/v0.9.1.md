# MATER 0.9.1 — Private Alpha Hardening

MATER 0.9.1 is the final small private-alpha feedback build planned before the public v1 release pass. It concentrates on destructive-data safeguards, reproducible testing across unusual and large Stockholm alignments, and useful bug reports. The repository and release remain private; no paid signing/notarization or Zenodo setup is included.

## Safety and support

- Files with Stockholm validation errors now display a prominent red save-protection banner. MATER refuses to save malformed output unless the user accepts an explicit per-document warning override; the override remains visibly orange and can be relocked.
- **Changes → Copy Diagnostics** captures the app/build, macOS and architecture, alignment dimensions, structure counts, validation and integrity state, and R-scape path. It contains no sequences or annotation-row contents.
- Structured GitHub bug and feature forms emphasize minimal synthetic examples and warn against sharing unpublished biological data.
- `PRIVACY.md` documents that normal editing is local, no telemetry or automatic crash reporting is present, and diagnostics are never submitted automatically.

## Validation coverage

- 10,000 deterministic randomized alignment edits pass width, ungapped-sequence, `#=GR` attachment, WUSS, stable-validation, and save/reopen invariants, followed by malformed-input fuzzing.
- Randomized document tests verify exact undo and redo of sequence-plus-annotation gap moves.
- An official-current Rfam corpus audit passed 250 evenly sampled SEED alignments from 4,227 families, including `#=GR` and letter-pseudoknot cases.
- Offscreen GUI tests exercise rendering in the biological color modes, distant navigation, linked protected edits, undo/redo, save/reopen, and bounded PDF/SVG export from alignments up to 5,000 × 1,000 and 200 × 10,000.
- Exact duplicate sequence patterns are collapsed into mathematically equivalent zero-length GSC subtrees, preserving relative R2R consensus weights while avoiding cubic clustering over redundant leaves. The stress pass also fixed a PDFKit tile-document lifetime stall in large multipage exports.
- R-scape/R2R/CaCoFold fixtures cover paths containing spaces, ordinary and pseudoknotted input, missing or incomplete installations, absent drawings/output, malformed output, nonzero failures, and cancellation.

The normal GitHub Actions workflow now runs core tests, randomized properties, and the quick GUI matrix on every push. A monthly/manual extended workflow runs the full GUI and current-Rfam audits. Official checkout and upload actions use their Node 24 releases.

## Install

1. Download `MATER-0.9.1-macOS-universal.zip` and its `.sha256` companion.
2. Optionally verify with `shasum -a 256 -c MATER-0.9.1-macOS-universal.zip.sha256`.
3. Unzip and drag `MATER.app` into Applications.
4. On first launch, right-click MATER and choose **Open**. If macOS still blocks it, allow MATER under **System Settings → Privacy & Security** and try again.

The app supports Apple Silicon and Intel Macs running macOS 13 or newer. It is ad-hoc signed and not Apple-notarized.

## Feedback priorities

Please prioritize any unintended sequence or `#=GR` movement, save/reopen mismatch, invalid-save protection failure, parser failure on a valid Stockholm file, repeatable crash/hang, R-scape cancellation/failure problem, or incorrect pseudoknot interpretation. Use **Changes → Copy Diagnostics** and attach only sanitized or synthetic data.
