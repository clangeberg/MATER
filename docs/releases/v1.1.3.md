# MATER 1.1.3

MATER 1.1.3 is a citation and archival release. The editor behavior is unchanged from 1.1.2.

## Main changes

- MATER releases are connected to Zenodo for persistent, versioned software archiving.
- `CITATION.cff` now includes the author's ORCID and University of California, Berkeley affiliation.
- The release version is updated throughout the app, user guide, privacy statement, and download instructions.

## Install

Download `MATER-1.1.3-macOS-universal.zip`, unzip it, and move `MATER.app` to Applications.

MATER is ad-hoc signed but not Apple-notarized. On first launch, right-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**. If macOS reports that the official release download is damaged, run:

```bash
xattr -d com.apple.quarantine /Applications/MATER.app
```

Only bypass quarantine for a copy downloaded from this release page.

## Verification

The standard core, randomized-edit, document-regression, and quick GUI stress suites are run before packaging. The universal ZIP and its SHA-256 checksum are attached to the GitHub release.
