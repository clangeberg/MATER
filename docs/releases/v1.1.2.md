# MATER 1.1.2

MATER 1.1.2 adds direct deletion of selected sequence rows.

## Main changes

- **Alignment tools → Delete selected sequences…** removes the active sequence row or every sequence row in a multi-row selection.
- A confirmation dialog lists the affected sequence names before changing the alignment.
- Matching `#=GR` per-residue annotation rows are removed with their owning sequences.
- Deletion is blocked while Alignment Integrity mode is locked and when it would remove every sequence.
- The complete operation is Undoable.

## Install

Download `MATER-1.1.2-macOS-universal.zip`, unzip it, and move `MATER.app` to Applications.

MATER is ad-hoc signed but not Apple-notarized. On first launch, right-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**. If macOS reports that the official release download is damaged, run:

```bash
xattr -d com.apple.quarantine /Applications/MATER.app
```

Only bypass quarantine for a copy downloaded from this release page.

## Verification

The existing sequence-removal regression verifies that deleting a sequence also removes its attached `#=GR` row and retains the remaining alignment. The standard core, randomized-edit, and quick GUI stress suites are run before packaging.
