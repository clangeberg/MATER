# MATER 1.1.0

MATER 1.1 focuses on manual-alignment speed, predictable structure editing, and keyboard discoverability.

## Main changes

- Selected sequence cells can be dragged horizontally through gaps. The canvas updates during the drag, shows whether movement is valid, and records the entire gesture as one Undo action.
- A single selected paired base now moves its complete fine stem arm. **Link stem arms** is off by default and remains available when both arms should move in register.
- The toolbar distinguishes **Open row gap** from **Insert column**, and movement failures describe the blocking edge.
- Direct `SS_cons` edits are pair-safe. Removing one endpoint removes its mate; new WUSS pairs are entered as complete pairs; unbalanced structure paste is rejected.
- The default keyboard preset follows Yaale conventions for movement, columns, search, navigation, coloring, and standard editing. MATER Classic remains available.
- **Settings → Keyboard** provides editable primary and alternate bindings, conflict reporting, and resets.
- New local tools provide extreme push, residue justification, gap-safe transpose, reverse search, go-to row/column, alignment audit/statistics, coordinate/GSC display sorting, column bookmarks, hairpin annotation, consensus writing, previewed sequence deletion, and safe column permutation.
- Non-dominant residue coloring, fixed-width font selection, and a fully in-app offline guide improve inspection and onboarding.

Network login, remote sequence extension, hit-coordinate correction, and hit-through-motif operations are not included.

## Install

Download `MATER-1.1.0-macOS-universal.zip`, unzip it, and move `MATER.app` to Applications.

MATER is ad-hoc signed but not Apple-notarized. On first launch, right-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**. If macOS reports that the official release download is damaged, run:

```bash
xattr -d com.apple.quarantine /Applications/MATER.app
```

Only bypass quarantine for a copy downloaded from this release page.

## Verification

The release was checked with the core and document regression suites, 10,000 randomized safe edits plus malformed-input fuzzing, and GUI stress cases at 100 × 1,000 and 500 × 1,000 cells. The universal Apple-silicon/Intel package is generated by the repository release script and accompanied by a SHA-256 checksum.

The compact structural-problem heatmap remains a screen-only navigation aid and is intentionally omitted from PDF/SVG output. R-scape and CaCoFold remain optional external workflows and are not bundled.
