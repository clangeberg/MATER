# MATER 0.8.0 Alpha 1

This is a closed-alpha pre-release for invited testers. MATER is a native macOS editor for manual curation of structure-aware RNA alignments in Stockholm format.

## Highlights

- **Suggest fixes** can optimize both complete helix arms and up to three neighboring unpaired columns, including bounded multi-column gap redistribution with a leave-one-out GSC-weighted profile.
- **Auto-refine copy** coordinates helix-arm windows and iterates safe structural improvements to a local fixed point without changing alignment width, annotations, or any ungapped sequence.
- Gapped and missing stems remain neutral: they are treated as possible structural variants rather than pairing violations or refinement failures.
- Optional external R-scape integration runs evaluate-given-structure (`-s`) analysis and retains the exact input snapshot, pairwise `.cov` table, `.power` table, R2R PDF/SVG drawing, and run log.
- A closable in-window PDFKit panel provides a zoomable R2R preview, concise statistics, power guidance, cancellation, and direct access to all retained files.
- Missing or invalid R-scape installations produce a clear, nonfatal message, with **Locate R-scape…** as a remembered fallback when it is not in `PATH`.
- Wrapped/interleaved Stockholm blocks are joined into complete logical rows on open, preventing duplicate-row crashes while retaining metadata/comments and writing a normalized single-block file.
- Stem inference tolerates up to two total bulged arm columns, so small insertions no longer split one helix into unrelated colors.
- New **Element** coloring assigns one color to nested/overlapping and crossing stems in the same topology-derived major structural element, including connected pseudoknot networks.
- R-scape selection accepts its executable, `bin` folder, installation folder, or `src/R-scape`; MATER prefers the installed `bin/R-scape` beside R2R and explains the Finder-versus-Terminal PATH difference.

## Install

1. Download `MATER-0.8.0-alpha.1-macOS-universal.zip` and verify it with the attached SHA-256 file if desired.
2. Unzip it and drag `MATER.app` into Applications.
3. On first launch, right-click MATER and choose **Open**. If macOS still blocks it, allow MATER under **System Settings → Privacy & Security**.

The app supports macOS 13 or newer on Apple Silicon and Intel Macs. It is ad-hoc signed but not Apple-notarized, so the first-launch warning is expected for this supervised alpha.

R-scape analysis is optional and requires a separate R-scape installation with the R2R/Perl components used for drawing. MATER itself opens and edits alignments normally when R-scape is absent.

## Alpha safety

- Work on a duplicate of important alignments and keep versioned originals.
- Leave **Alignment locked** during ordinary alignment curation.
- Treat suggested and auto-refined output as candidates requiring biological review. “Refined” means locally converged for MATER's bounded helix-window moves, not a globally optimal alignment or newly inferred structure.
- The original alignment is never overwritten by **Auto-refine copy**.
- Interpret R-scape output using its `.power` table and phylogenetic assumptions; absence of significant pairs can be inconclusive at low detection power.
- Remove unpublished biological data and sensitive identifiers before attaching an alignment or R-scape output to an issue.

## Known limitations

- One Stockholm alignment per file; wrapped/interleaved rows are accepted but are saved in normalized single-block form.
- No de novo alignment, profile alignment, structure prediction, or covariance-model search.
- Refinement searches bounded helix-plus-three-column windows and local moves; it is not a global multiple-sequence realigner.
- Statistical analysis depends on a separately installed compatible R-scape/R2R distribution; MATER does not bundle or update it and does not overlay E-values on alignment cells.
- Major-element boundaries are inferred from topology; dot bracket cannot encode arbitrary named laboratory/domain groupings.
- The compact structural-problem heatmap is intentionally editor-only and is not included in alignment PDF/SVG export.
- No built-in updater, telemetry, or crash-reporting service.
