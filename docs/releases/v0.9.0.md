# MATER 0.9.0 — Private Alpha

This is the final planned private-alpha feedback build before MATER's first public release. The repository and release remain private; share access only with invited collaborators. MATER 0.9.0 prioritizes Stockholm data safety, testable large-alignment behavior, and a more complete macOS application experience.

## Most important safety fix

All width-preserving residue rearrangements now move matching `#=GR` rows through the identical full-column permutation. PP, per-sequence SS, and other residue annotations remain attached to their residue ordinal during manual shifts, gap opening/closing, suggested edits, paste/reversion, and Wiggle-refine. The move preserves mixed `.` and `-` gap notation and is verified before commit.

Versions through 0.8.1 did not provide this guarantee. If an older build was used to move residues in an alignment containing `#=GR`, compare the saved file with its original before downstream use.

## Other changes

- Wrapped Stockholm blocks are joined only after a real or unambiguous block boundary. Same-block duplicate sequence names remain separate and receive a specific validation error.
- Validation issue identifiers are stable, and repeated pair lookups use the document's cached structure analysis.
- Wiggle-refine reports pass, sequence, and accepted-edit progress. Its toolbar button becomes **Cancel** while running; cancellation writes no partial output and leaves the source untouched.
- Recovery snapshots are isolated by file path, automatically expire after 30 days, and can be cleared from Settings.
- MATER now has native About, Settings, and Help commands. Settings manages residue colors, the R-scape path, and recovery data; Help opens the bundled version-matched guide.
- The bundle identifier is now `io.github.clangeberg.mater`. Existing residue-color and R-scape-path preferences are migrated from the earlier defaults domain.
- The repository now includes a BSD 3-Clause license, citation metadata, a real application screenshot, a reproducible performance benchmark, portable SDK selection, release packaging, and macOS GitHub Actions CI.

## Performance check

On the release-development Mac, the checked-in synthetic 5,000-sequence × 1,000-column benchmark measured approximately 1.10 s to parse, 0.28 s for full analysis, 0.27 s for a protected shift, and 0.28 s to reanalyze. Run `./scripts/benchmark-performance.sh 5000 1000` to measure another machine. This benchmark covers the model/analysis pipeline, not frame rendering.

## Install

1. Download `MATER-0.9.0-macOS-universal.zip` and its `.sha256` companion.
2. Optionally verify with `shasum -a 256 -c MATER-0.9.0-macOS-universal.zip.sha256`.
3. Unzip and drag `MATER.app` into Applications.
4. On first launch, right-click MATER and choose **Open**. If macOS still blocks it, allow MATER under **System Settings → Privacy & Security** and try again.

The universal binary supports Apple Silicon and Intel Macs running macOS 13 or newer. It is ad-hoc signed but not Apple-notarized; this release does not require a paid Apple Developer Program membership.

## Feedback priorities

Please report any unintended sequence or `#=GR` registration change, parser error on a valid wrapped file, repeatable hang/crash, failed cancellation, recovery mix-up, or save/reopen difference. Include MATER build 14, macOS version, Mac processor, exact steps, and a small sanitized Stockholm reproducer when possible.

See the [complete user guide](https://github.com/clangeberg/MATER/blob/v0.9.0/docs/MATER-User-Guide.md), [Rfam examples](https://github.com/clangeberg/MATER/tree/v0.9.0/Examples/Rfam), and [issue tracker](https://github.com/clangeberg/MATER/issues).
