# MATER 1.1.1

MATER 1.1.1 is a focused manual-movement fix with a refreshed project page.

## Main changes

- Selecting an unpaired nucleotide next to an occupied run can now push the complete contiguous block toward the first available gap. The block no longer needs to be selected manually before moving it.
- Stem-aware movement remains unchanged: a selected paired nucleotide still expands through its fine stem arm, and **Link stem arms** remains opt-in.
- Multi-row pushes remain atomic. MATER extends through occupied columns until every selected sequence row has a gap; if the alignment edge is reached first, nothing moves.
- Matching `#=GR` annotations travel with the expanded sequence move, and the complete destination block remains selected for repeated movement.
- **Reset to Yaale-compatible** now applies the Yaale bindings immediately and after relaunch. MATER Classic movement and column shortcuts are confined to the Classic preset, and stale saved bindings can no longer override the named preset.
- The README now uses a clearer centered project header, build/release badges, direct navigation, an overview table, and a more visible first-launch notice.

## Install

Download `MATER-1.1.1-macOS-universal.zip`, unzip it, and move `MATER.app` to Applications.

MATER is ad-hoc signed but not Apple-notarized. On first launch, right-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**. If macOS reports that the official release download is damaged, run:

```bash
xattr -d com.apple.quarantine /Applications/MATER.app
```

Only bypass quarantine for a copy downloaded from this release page.

## Verification

The expanded movement path is covered by a document regression test using an unpaired flanking nucleotide, an adjacent stem, and a registered `#=GR` posterior-probability row. Shortcut regressions verify preset separation, live reset behavior, stale-data repair, and relaunch persistence. The standard core, property, and quick GUI regression suites are also run before packaging.
