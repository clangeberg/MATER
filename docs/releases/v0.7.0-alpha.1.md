# MATER 0.7.0 Alpha 1

This is a closed-alpha pre-release for invited testers. MATER is a native macOS editor for manual curation of structure-aware RNA alignments in Stockholm format.

## Highlights

- Alignment Integrity mode protects ordered ungapped sequence data during routine gap editing and checks it again before saving.
- Structure-aware stem and pseudoknot coloring supports `<>`, `()`, `[]`, `{}`, and `A/a` through `Z/z` WUSS pairs.
- Residue and descriptive pair-variation color modes, configurable A/C/G/U colors, paired-partner highlighting, and column selection from structural annotation rows.
- R2R-compatible GSC-weighted sequence consensus plus entropy, gap-frequency, occupied-pair violation, and structure-block overview tracks.
- Structural Quality Inspector, problem navigation, display-only filtering/sorting, and previewed gap-only suggestions.
- One-click **Auto-refine copy** iteratively applies conservative gap-only structural improvements without per-edit approval, writes a new Stockholm file, and never modifies the source alignment.
- Search, change tracking, recovery snapshots, vector PDF/SVG export, and large-alignment navigation.
- A comprehensive user guide and four focused Rfam SEED teaching alignments.

## Install

1. Download `MATER-0.7.0-alpha.1-macOS-universal.zip` and verify it with the attached SHA-256 file if desired.
2. Unzip it and drag `MATER.app` into Applications.
3. On first launch, right-click MATER and choose **Open**. If macOS still blocks it, allow MATER under **System Settings → Privacy & Security**.

The app supports macOS 13 or newer on Apple Silicon and Intel Macs. It is ad-hoc signed but not Apple-notarized, so the first-launch warning is expected for this supervised alpha.

## Alpha safety

- Work on a duplicate of important alignments and keep versioned originals.
- Leave **Alignment locked** during ordinary alignment curation.
- Treat auto-refined output as a candidate alignment requiring biological review. “Refined” means locally converged for MATER's supported adjacent gap moves, not a globally optimal alignment or newly inferred structure.
- The original alignment is never overwritten by **Auto-refine copy**.
- Remove unpublished biological data and sensitive identifiers before attaching an alignment to an issue.

## Known limitations

- One non-interleaved Stockholm alignment per file; repeated multi-block rows are not concatenated.
- No de novo alignment, profile alignment, structure prediction, covariance-model search, or statistical covariation significance test.
- Suggested and automatic edits are local one-column, gap-only operations.
- The compact structural-problem heatmap is not included in PDF/SVG export.
- No built-in updater, telemetry, or crash-reporting service.
