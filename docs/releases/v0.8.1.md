# MATER 0.8.1

> **Safety advisory:** versions through 0.8.1 can leave `#=GR` per-residue annotations at their old columns after a sequence gap shift, including Wiggle-refine. Upgrade to v0.9.0 before editing alignments containing `#=GR` rows. Existing output should be compared with its pre-edit source before downstream use.

This is a closed-alpha release for invited testers. MATER is a native macOS editor for manual curation of structure-aware RNA alignments in Stockholm format.

## Highlights

- **Wiggle-refine** is the new name for MATER's one-click, alignment-wide, gap-only local refinement. It writes a unique `NAME-MATER-wiggle-refined.sto` without changing the source.
- **CaCoFold-refine** uses a separately installed R-scape in evaluate-given-structure CaCoFold mode and writes a unique `NAME-MATER-CaCoFold-refined.sto`.
- The focused CaCoFold workflow retains only the improved Stockholm alignment. Its tables, logs, drawings, and other intermediate files stay in a private temporary directory and are deleted after validation.
- Both refinement outputs open directly as new MATER documents instead of being handed to the macOS default text editor.
- Missing or invalid R-scape installations produce a clear, nonfatal message. The chooser accepts the executable, `bin` folder, installation folder, or a development `src/R-scape` path.
- The existing **Run R-scape** workflow remains separate and continues to retain the input snapshot, `.cov` and `.power` tables, run log, and R2R PDF/SVG drawing.
- CaCoFold output is parsed and checked for fatal Stockholm validation errors before it is saved or opened.

## Install

1. Download `MATER-0.8.1-macOS-universal.zip` and verify it with the attached SHA-256 file if desired.
2. Unzip it and drag `MATER.app` into Applications.
3. On first launch, right-click MATER and choose **Open**. If macOS still blocks it, allow MATER under **System Settings → Privacy & Security**.

The app supports macOS 13 or newer on Apple Silicon and Intel Macs. It is ad-hoc signed but not Apple-notarized, so the first-launch warning is expected for this supervised alpha.

R-scape and CaCoFold are optional and are not bundled. MATER opens and edits alignments normally when R-scape is absent. The CaCoFold integration was exercised with R-scape 2.6.16.

## Alpha safety

- Work on a duplicate of important alignments and keep versioned originals.
- Leave **Alignment locked** during ordinary alignment curation.
- Treat Wiggle-refined and CaCoFold-refined output as computational candidates requiring biological review.
- Neither refinement action overwrites the source or an earlier generated result.
- Preserve the source and refined `.sto` files if CaCoFold materially contributes to an analysis; the focused workflow intentionally discards its intermediates.
- Use the separate **Run R-scape** action when pairwise significance tables, power estimates, logs, or an R2R drawing are needed.
- Remove unpublished biological data and sensitive identifiers before attaching an alignment or R-scape output to an issue.

## Known limitations

- One Stockholm alignment per file; wrapped/interleaved rows are accepted but are saved in normalized single-block form.
- No de novo or profile alignment and no covariance-model search.
- Wiggle-refine searches bounded helix-plus-three-column windows and local moves; it is not a global multiple-sequence realigner.
- CaCoFold-refine depends on a separately installed compatible R-scape and does not retain its diagnostics after a successful run.
- Statistical analysis depends on a separately installed compatible R-scape/R2R distribution; MATER does not bundle or update it and does not overlay E-values on alignment cells.
- Major-element boundaries are inferred from topology; dot bracket cannot encode arbitrary named laboratory/domain groupings.
- The compact structural-problem heatmap is intentionally editor-only and is not included in alignment PDF/SVG export.
- No built-in updater, telemetry, or crash-reporting service.
