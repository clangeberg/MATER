# MATER 1.0.0

This is the first public release of MATER.

I built MATER because manually improving an RNA alignment is much faster when the sequence, structure, and problem columns stay visible together. The goal is a practical editor for the decisions that still need a person, especially in alignments with pseudoknots.

## What is included

- A native macOS Stockholm editor for Apple-silicon and Intel Macs
- Stem, structural-element, pair-variation, and configurable residue colors
- Pseudoknot-aware pairing, partner selection, and linked helix-arm movement
- Alignment Integrity checks that protect ungapped sequences and attached `#=GR` annotations
- R2R-style sequence consensus plus entropy, gap, and occupied-pair problem tracks
- Structural inspection, local suggested edits, and cancellable whole-alignment Wiggle-refine
- Optional R-scape evaluate-given-structure and CaCoFold-refine integration
- PDF and SVG alignment export
- A complete user guide and four small Rfam teaching alignments

## What I checked

Before tagging 1.0.0, I ran the core regression suite, 10,000 deterministic randomized edit operations, malformed-input fuzzing, the full large-alignment GUI matrix, a 250-family Rfam SEED audit, real R-scape/CaCoFold checks, and a clean universal-app packaging pass.

The randomized and regression tests specifically check that gap edits do not change ungapped sequence order or detach per-residue annotations. The GUI checks cover alignments from 100 × 1,000 through 5,000 × 1,000 and 200 × 10,000.

## Install

Download `MATER-1.0.0-macOS-universal.zip`, unzip it, and move `MATER.app` to Applications.

MATER is ad-hoc signed but not Apple-notarized. On first launch, right-click the app and choose **Open**, or allow it under **System Settings → Privacy & Security**. If macOS reports that the official release download is damaged, run:

```bash
xattr -d com.apple.quarantine /Applications/MATER.app
```

Only bypass quarantine for a copy downloaded from this release page.

## Boundaries

MATER edits an existing alignment; it is not a de novo aligner, covariance-model builder, or independent statistical covariation test. R-scape remains a separate installation. The compact problem heatmap is a screen-only navigation aid and is deliberately not part of PDF/SVG export.

Please keep versioned copies of important alignments and report reproducible problems through GitHub Issues. A small sanitized Stockholm example is usually the most useful bug report.
