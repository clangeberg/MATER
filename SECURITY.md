# Security

MATER is a local desktop application and does not include an account service, telemetry, or an automatic updater.

If you find a security or privacy problem, please do not open a public issue with exploit details or sensitive data. Use the repository's **Security → Report a vulnerability** link to start a private GitHub security advisory.

For an ordinary crash, rendering problem, or Stockholm parsing bug that does not expose private data or execute untrusted content, use the public bug-report form instead.

Never include unpublished biological data, credentials, or identifying paths unless they are essential and you are permitted to share them. A minimal synthetic file is preferred.
